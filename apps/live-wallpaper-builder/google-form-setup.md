# LiveWallpaperBuilder support form

Published form:
https://docs.google.com/forms/d/e/1FAIpQLSejrmGYj4gSuewTWGvwrR7jRYRpMaQqR3u57jAnU1Q0ANlP1w/viewform?usp=dialog

Google Forms does not provide a complete per-respondent language switch. Keep this short form
bilingual so Japanese and English responses remain in one response sheet.

## Form settings

- Title: `LiveWallpaperBuilder | 機能リクエスト・お問い合わせ / Feature Requests & Contact`
- Do not require sign-in.
- Do not collect email addresses automatically.
- Do not allow file uploads.
- Allow response editing only if it does not require sign-in.
- Confirmation:
  `送信ありがとうございました。内容を確認します。 / Thank you. Your message has been received.`

## Description

```text
機能のご要望、不具合のご報告、ご質問をお送りください。
返信が必要な場合のみメールアドレスをご入力ください。
画像・動画、パスワード、その他の機微な情報は送信しないでください。

Use this form for feature requests, bug reports, and questions.
Enter your email address only if you need a reply.
Do not submit images, videos, passwords, or other sensitive information.

Privacy Policy:
https://minorimn.com/apps/live-wallpaper-builder/privacy/
```

## Questions

1. Required multiple choice: `お問い合わせ種別 / Message type`
   - `機能リクエスト / Feature request`
   - `不具合報告 / Bug report`
   - `質問 / Question`
   - `その他 / Other`
2. Required multiple choice: `希望する返信言語 / Preferred reply language`
   - `日本語 / Japanese`
   - `English / 英語`
   - `返信不要 / No reply needed`
3. Required paragraph: `内容 / Message`
4. Optional short answer: `アプリのバージョン / App version`
5. Optional short answer: `Android バージョン・端末名 / Android version and device model`
6. Optional short answer with email validation: `返信先メールアドレス / Reply email address`
7. Required checkbox:
   `入力内容を問い合わせ対応とアプリ改善に利用することに同意します。 / I agree that my submission may be used to respond and improve the app.`
