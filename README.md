# MinoriMn.github.io

## 公開構成

- `/` - 公開アプリ情報の入口
- `/apps/live-wallpaper-builder/` - LiveWallpaperBuilder のサポート入口
- `/apps/<app-slug>/privacy/` - アプリごとの公開プライバシーポリシー
- `/apps/<app-slug>/faq/` - アプリごとのQ&A
- `/portfolio/` - Cloudflare Accessで保護するポートフォリオ

Cloudflare Accessの設定手順は [docs/cloudflare-access-setup.md](docs/cloudflare-access-setup.md) を参照してください。
